# Hồ cá đại dương

Trang web mô phỏng một khung cảnh dưới đại dương với các loài sinh vật biển, thợ lặn và hiệu ứng bong bóng chuyển động. Dự án được xây dựng bằng HTML và CSS thuần.

- **Học phần:** Thiết kế Web

## Xem trang web

Mở file [`index.html`](./index.html) bằng trình duyệt. Không cần cài đặt thêm thư viện hay chạy máy chủ.

## Nội dung dự án

- `index.html`: cấu trúc và các thành phần của cảnh đại dương.
- `mystyle.css`: hình nền, bố cục và các hiệu ứng chuyển động.
- `img/`: hình nền và hình ảnh sinh vật biển được sử dụng trong trang.

## Công nghệ

- HTML5
- CSS3 (animation và keyframes)
